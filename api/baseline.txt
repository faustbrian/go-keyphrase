package keyphrase // import "github.com/faustbrian/go-keyphrase"

Package keyphrase provides shared cryptographic randomness and entropy contracts
for password, passphrase, and BIP-39 mnemonic generation.

It does not hash passwords, manage wallets, derive wallet keys, store secrets,
or distribute secret material.

TYPES

type Error struct {
	Code  ErrorCode
	Cause error
}
    Error is a typed, secret-safe generation error.

    Error deliberately omits the wrapped error text. Callers that need the
    underlying cause may inspect it with errors.Is or errors.As, but should not
    log arbitrary source errors without reviewing their disclosure behavior.

func (e *Error) Format(state fmt.State, _ rune)
    Format prevents wrapped source diagnostics from appearing in debug output.

func (e *Error) MarshalText() ([]byte, error)
    MarshalText omits wrapped source diagnostics from encoded output.

type Option func(*Selector) error
    Option configures a Selector.

func WithMaxAttempts(maxAttempts int) Option
    WithMaxAttempts bounds rejected samples from a faulty or hostile source.

type Secret []byte
    Secret is a caller-owned byte slice whose fmt representation is always
    redacted. Convert it explicitly to []byte or string only at a reviewed
    integration boundary.

func (s Secret) Clear()
    Clear overwrites the current backing array as a best-effort measure. Go and
    the operating system may retain compiler, runtime, string, or page copies.

func (Secret) Format(state fmt.State, _ rune)
    Format prevents accidental disclosure through logging and debugging verbs.

func (Secret) LogValue() slog.Value
    LogValue prevents disclosure through the standard structured logger.

func (Secret) MarshalText() ([]byte, error)
    MarshalText prevents disclosure through standard text and JSON encoders.

type Selector struct {
	// Has unexported fields.
}
    Selector performs bounded rejection sampling from a Source.

func DefaultSelector() *Selector
    DefaultSelector returns a selector backed by crypto/rand.

func NewSelector(source Source, options ...Option) (*Selector, error)
    NewSelector constructs a selector using source.

func (s *Selector) BigInt(ctx context.Context, upper *big.Int) (*big.Int, error)
    BigInt returns a uniformly distributed arbitrary-precision value in [0,
    upper). The returned integer never aliases upper.

func (s *Selector) Fill(ctx context.Context, destination []byte) error
    Fill writes cryptographic random bytes into destination. On failure it
    clears destination so callers never observe a partial secret.

func (s *Selector) Index(ctx context.Context, upper uint64) (uint64, error)
    Index returns a uniformly distributed value in [0, upper).

type Source interface {
	ReadContext(ctx context.Context, destination []byte) (int, error)
}
    Source supplies cryptographic random bytes and participates in cancellation.
    Implementations must fill as much of destination as possible and must return
    promptly after ctx is canceled.

package bip39 // import "github.com/faustbrian/go-keyphrase/bip39"

Package bip39 implements BIP-39 mnemonic encoding, validation, language
detection, and seed derivation. It does not implement wallets, addresses,
private-key custody, BIP-32, or BIP-44.

FUNCTIONS

func List(language Language) (*wordlist.List, error)
    List returns an immutable, validated official list.

func Seed(ctx context.Context, mnemonic Mnemonic, passphrase string) (keyphrase.Secret, error)
    Seed derives the 64-byte BIP-39 seed using NFKD and PBKDF2-HMAC-SHA512 with
    2,048 iterations. The returned buffer is caller-owned.

package password // import "github.com/faustbrian/go-keyphrase/password"

Package password generates uniformly distributed passwords under explicit
character and required-class policies.

FUNCTIONS

func Validate(policy Policy, encoded []byte) error
    Validate reports whether encoded is a complete UTF-8 password satisfying
    policy. The returned error never includes encoded.

	Alphabet           []byte

type Generator struct {
	// Has unexported fields.

func (g *Generator) Generate(ctx context.Context, policy Policy) (keyphrase.Secret, error)
    Generate returns a caller-owned UTF-8 buffer. No partial secret is returned

    GenerateBytes returns a complete caller-owned byte password.

    GenerateBytesInto fills destination only when it can hold the complete
    fixed-length output.

func (g *Generator) GenerateInto(ctx context.Context, destination []byte, policy Policy) (int, error)
    GenerateInto copies a complete generated password into destination.
    It leaves destination unchanged when generation fails or the buffer is too
    small.

	Alphabet           string
	Required           []Class
	Excluded           string
	MinimumEntropyBits float64
}
    Policy defines a Unicode password distribution. Length is measured in
    Unicode code points, not encoded bytes.
