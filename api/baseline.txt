package keyphrase // import "github.com/faustbrian/go-keyphrase/v2"

Package keyphrase provides shared cryptographic randomness and entropy contracts
for password, passphrase, and BIP-39 mnemonic generation.

It does not hash passwords, manage wallets, derive wallet keys, store secrets,
or distribute secret material. Exact output counts describe the configured
distribution, not resistance after disclosure, edits or downstream
normalization. Uniform generation relies on a uniform, independent Source;
custom source quality, cancellation and concurrency safety are caller-owned.

Contexts must be nonnil when checked. Cancellation is cooperative around source
reads; password preparation/unranking and phrase assembly are not interruptible.
BIP-39 seed derivation checks before and after fixed PBKDF2. Secret buffers
are caller-owned but slice aliases share storage; clearing is best effort and
does not erase immutable strings or a Mnemonic's retained entropy. The package
creates no background goroutines or shutdown owner.

type Option func(*Selector) error
    Option configures a Selector.

func WithMaxAttempts(maxAttempts int) Option
    WithMaxAttempts bounds candidate draws per Index or BigInt operation.
    It requires a positive count; it does not bound partial-read calls or time
    spent inside the source. The default is 128 candidate draws.

type Secret []byte
    Secret is a caller-owned byte slice whose fmt representation is always
    redacted. Convert it explicitly to []byte or string only at a reviewed
    integration boundary. Assignment or []byte conversion shares its mutable
    backing array; redaction is not encryption and does not cover arbitrary
    binary encoders or wrappers that explicitly extract the bytes.

func (s Secret) Clear()
    Clear overwrites the slice's visible length as a best-effort measure,
    not unused capacity or independently copied buffers. Go and the operating
    system may retain compiler, runtime, string, or page copies. Aliases of this
    same slice storage observe the clearing; independent copies and immutable
    strings do not.

func (Secret) Format(state fmt.State, _ rune)
    Format prevents accidental disclosure through logging and debugging verbs.

func (Secret) LogValue() slog.Value
    LogValue prevents disclosure through the standard structured logger.

func (Secret) MarshalText() ([]byte, error)
    MarshalText prevents disclosure through standard text and JSON encoders.

type Selector struct {
	// Has unexported fields.
}
    Selector performs bounded rejection sampling from a Source. Uniform and
    independent source bytes are required for uniform results. Selector retains
    source without wrapping it in a lock; concurrency safety depends on source.
    The zero value is invalid. Contexts must be nonnil when an operation checks
    them; the library cannot interrupt a Source call that ignores cancellation.

func DefaultSelector() *Selector
    DefaultSelector returns a selector backed by crypto/rand. It checks context
    before random reads, but cannot interrupt an in-progress crypto/rand read.

func NewSelector(source Source, options ...Option) (*Selector, error)
    NewSelector constructs a selector retaining source. Options run in order,
    are not retained, and may return their own errors. Nil source/option values
    are rejected; custom source quality and sharing remain caller-owned.

func (s *Selector) BigInt(ctx context.Context, upper *big.Int) (*big.Int, error)
    BigInt returns a uniformly distributed arbitrary-precision value in [0,
    upper), assuming uniform independent source bytes. upper must be positive
    and must not be modified during the call. At most 2^20 bits are sampled; the
    returned integer never aliases upper. A bound of one needs no source read.

func (s *Selector) Fill(ctx context.Context, destination []byte) error
    Fill writes cryptographic random bytes into destination. On failure it
    clears destination before returning an error. It allows at most 128 KiB;
    a valid selector with an empty destination succeeds without reading or
    checking ctx. Callers must not observe or mutate destination during a call;
    it can contain partial bytes until an error clears it.

func (s *Selector) Index(ctx context.Context, upper uint64) (uint64, error)
    Index rejection-samples a value in [0, upper), uniformly if source bytes are
    uniform and independent. upper must be nonzero. A bound of one returns zero
    without a read after checking ctx. Cancellation is checked before reads,
    not again after a successful final read.

type Source interface {
	// ReadContext reads into caller-provided space. Selector accepts positive
	// partial progress with nil error, but rejects any nonnil error, even with
	// a full count. Zero or invalid counts fail without a retry loop.
	ReadContext(ctx context.Context, destination []byte) (int, error)
}
    Source supplies cryptographic random bytes and participates in cancellation.
    Implementations must fill as much of destination as possible and must return
    promptly after ctx is canceled. Randomness quality is a trusted caller
    assumption, not verified by this interface or by statistical test helpers.

package bip39 // import "github.com/faustbrian/go-keyphrase/v2/bip39"

Package bip39 implements BIP-39 mnemonic encoding, validation, language
detection, and seed derivation. It does not implement wallets, addresses,
private-key custody, BIP-32, or BIP-44.

FUNCTIONS

func List(language Language) (*wordlist.List, error)
    List returns a shared immutable, validated official list. The first
    supported call loads all ten embedded lists once; any load failure is cached
    for later calls, without retry or network refresh. Metadata pins the source
    revision.

func Seed(ctx context.Context, mnemonic Mnemonic, passphrase string) (keyphrase.Secret, error)
    Seed derives the 64-byte BIP-39 seed using NFKD and PBKDF2-HMAC-SHA512
    with 2,048 iterations. Context cancellation is checked before and after
    the fixed, bounded derivation because the maintained primitive cannot be
    interrupted. The returned buffer is caller-owned. passphrase is limited to 1
    MiB before normalization. A wrong passphrase still derives a seed; it is not
    authenticated. The fixed BIP-39 parameters are for interoperability, not a
    recommendation for password storage. Strict FIPS-only short-salt rejection
    yields CodeDerivation and no seed; parameters are not silently changed.

type Mnemonic struct {
	// Has unexported fields.
}
    Mnemonic is an immutable validated BIP-39 mnemonic, safe for concurrent
    reads. The zero value is invalid for Seed. Private entropy remains stored
    for the value's lifetime; clearing an Entropy copy does not wipe this
    retained state.

func FromEntropy(entropy []byte, language Language) (Mnemonic, error)
    FromEntropy copies entropy and encodes 16, 20, 24, 28 or 32 bytes plus their
    SHA-256 checksum into an official list. It does not measure the input's
    random quality. The caller must not modify entropy during the call.

func Generate(ctx context.Context, entropyBits int, language Language, selector *keyphrase.Selector) (Mnemonic, error)
    Generate fills fresh entropy and creates its corresponding mnemonic. It
    consumes source bytes before language loading/validation, so an unsupported
    language can fail after a read without returning a mnemonic.

func Parse(phrase string) (Mnemonic, error)
    Parse detects the official language and validates the checksum. Vocabulary
    shared by multiple lists is reported as ambiguity instead of guessed,
    before trying checksums. Input must contain 1..65536 bytes; NFKD and Unicode
    Fields normalize spelling/whitespace, without case folding.

func ParseLanguage(phrase string, language Language) (Mnemonic, error)
    ParseLanguage validates phrase against an explicitly selected language using
    Parse's NFKD/whitespace and byte-size rules. It checks the BIP-39 checksum;
    checksum validity does not establish a mnemonic's source entropy quality.

    Entropy returns a caller-owned copy of the validated source entropy.

func (Mnemonic) Format(state fmt.State, _ rune)

func (Mnemonic) MarshalText() ([]byte, error)
    MarshalText prevents mnemonic disclosure through standard encoders.

    String returns the canonical mnemonic sentence. Japanese uses ideographic
    spaces as shown in the official vectors; seed derivation still applies NFKD.

    Words returns a copy of the mnemonic words.

package keyphrasetest // import "github.com/faustbrian/go-keyphrase/v2/keyphrasetest"

Package keyphrasetest provides deterministic sources and statistical test
helpers. Its distribution checks can detect obvious bias but do not certify a
cryptographic random source.

VARIABLES

var ErrInvalidSample = errors.New("keyphrasetest: invalid statistical sample")
    ErrInvalidSample reports an unusable statistical sample.


FUNCTIONS

func ChiSquared(counts []uint64) (float64, error)
    ChiSquared returns Pearson's statistic against equal expected counts,
    not a p-value or randomness certification. At least two bins and a nonzero
    total are required. The caller must keep the total representable by uint64;
    this helper does not check sum overflow. Floating-point arithmetic is
    approximate.

	// Has unexported fields.

package passphrase // import "github.com/faustbrian/go-keyphrase/v2/passphrase"

passphrases with optional independently generated password affixes. Uniform
selection assumes uniform independent source bytes. Parsing validates policy and
representation, not that the supplied phrase was randomly generated.

type Policy struct {
	// WordList is a nonnil immutable list, with at most 32768 entries. It is
	// shared, not cloned.

	// Words is the number of independently selected words with replacement,
	// from 2 through 128; repeated words are permitted.

}

package password // import "github.com/faustbrian/go-keyphrase/v2/password"

Package password generates uniformly distributed passwords under explicit
character and required-class policies, assuming uniform independent source
bytes. Unicode policies preserve code points without normalizing complete
outputs; downstream normalization can change the counted distribution.

FUNCTIONS

func Validate(policy Policy, encoded []byte) error
    Validate reports whether encoded is a complete UTF-8 password satisfying
    policy. It validates the floor's form but does not compare the distribution
    count against MinimumEntropyBits; use Analyze for that admission check.
    The returned error never includes encoded. No random-origin or strength
    claim is made by accepting a caller-supplied value.


TYPES

type ByteClass struct {
	// Name must be nonempty and labels this requirement.
	Name string
	// Bytes is a nonempty duplicate-free set from the original alphabet; at
	// least one byte must survive exclusions. Do not mutate it during a call.
	Bytes []byte
}
    ByteClass is a required set in a byte-alphabet policy.

type BytePolicy struct {
	// Length is the positive output byte count, at most 1024.
	Length int
	// Alphabet contains ordered distinct bytes, at most 256; zero and non-UTF-8
	// values are allowed. Do not mutate it during a call.
	Alphabet []byte
	// Required contains up to 16 possibly overlapping required sets, satisfied
	// at least once each. Do not mutate it or its Bytes slices during a call.
	Required []ByteClass
	// Excluded removes exact byte values before counting; it must have no
	// duplicates and must not be modified during a call.
	Excluded []byte
	// MinimumEntropyBits is a finite nonnegative floor compared with
	// approximate Bits by AnalyzeBytes and generation, not a source-quality
	// measurement.
	MinimumEntropyBits float64
}
    BytePolicy defines a distribution over arbitrary byte values, without
    Unicode normalization or text encoding. Its slices must remain stable during
    a call.

type Class struct {
	// Name must be nonempty; it labels the requirement, not a unique class

	// Characters is a nonempty duplicate/NFKD-collision-free UTF-8 set drawn

type Policy struct {
	// Length is the positive output code-point count, at most 1024; it is not a
	// grapheme or UTF-8 byte count.
	Length int
	// Alphabet is ordered UTF-8 with unique code points and no per-symbol NFKD
	// collisions, at most 4096 code points/16384 bytes.
	Alphabet string
	// Required contains up to 16 classes, each satisfied at least once; overlap
	// is allowed. Its slice must not be modified during a call.
	Required []Class
	// Excluded removes exact code points before counting/generation; it is not
	// a normalization or case-folding rule.
	Excluded string
	// MinimumEntropyBits is a finite nonnegative floor checked against
	// approximate Bits by Analyze and generation. Validate checks its form but
	// not whether the count meets it.
	MinimumEntropyBits float64
}
    Policy defines a Unicode password distribution. Length is measured in
    Unicode code points, not encoded bytes.

package wordlist // import "github.com/faustbrian/go-keyphrase/v2/wordlist"

Package wordlist validates and exposes immutable word lists with explicit
provenance metadata. Validation checks entries and checksum consistency,
not publisher authority or dictionary suitability for a threat model. Raw words
and order are preserved; normalization checks do not rewrite stored entries.

FUNCTIONS

func Checksum(words []string) string
    Checksum returns the SHA-256 checksum of newline-terminated UTF-8 entries.

type List struct {
	// Has unexported fields.
}
    List is an immutable validated word list, safe for concurrent read-only use.
    It must come from New or a validated embedded loader; its zero value does
    not satisfy list-construction guarantees. Methods require a nonnil receiver.

func New(metadata Metadata, words []string, options ...Option) (*List, error)
    New validates words and returns an immutable copy of the slice. It admits
    1..65536 entries of at most 1024 UTF-8 bytes each, rejecting whitespace,
    controls, exact duplicates and NFKD collisions without rewriting raw
    entries. Metadata strings are copied by value; SourceSHA256 is only
    shape-checked. Callers must not modify the input slice during validation.

func (l *List) Index(word string) (int, bool)
    Index returns the exact raw entry index without normalization or case
    folding.

func (l *List) Len() int
    Len returns the number of entries.

func (l *List) Metadata() Metadata
    Metadata returns the pinned list metadata.

func (l *List) Word(index int) (string, bool)
    Word returns the entry at index.

func (l *List) Words() []string
    Words returns a copy of all entries.

type Metadata struct {
	// ID is the nonempty caller-selected identity, not an authenticated
	// registry entry.
	ID string
	// Language is a nonempty descriptive language label, not validated against
	// a registry.
	Language string
	// Source records a nonempty source location; New does not fetch it.
	Source string
	// Version records a nonempty source version or revision without verifying
	// it.
	Version string
	// License is a nonempty provenance label, not a license compliance verdict.
	License string
	// ExpectedWords must equal the supplied entry count.
	ExpectedWords int
	// SHA256 is the hex SHA-256 of raw entries with a newline after each;
	// matching is case-insensitive and preserves entry order.
	SHA256 string
	// SourceSHA256 is the hex SHA-256 claimed for original source bytes. New
	// checks its shape, not those bytes; trusted provenance is separate.
	SourceSHA256 string
}
    Metadata pins provenance and integrity for a list.

type Option func(*config) error
    Option configures list validation.

func WithNFKD() Option
    WithNFKD requires every entry to already use BIP-39-compatible NFKD.

func WithUniquePrefix(length int) Option
    WithUniquePrefix rejects entries sharing the first length Unicode code
    points after NFC display normalization, not raw UTF-8 byte prefixes.
    Shorter entries use their whole normalized form. It checks uniqueness;
    Index does not accept abbreviations.

package eff // import "github.com/faustbrian/go-keyphrase/v2/wordlist/eff"

Package eff embeds the Electronic Frontier Foundation diceware word lists
with pinned source and integrity metadata. Embedded data is the word column in
original order, not the original indexed source rows. Each loader memoizes its
immutable list or failure; no network refresh or retry is performed.
