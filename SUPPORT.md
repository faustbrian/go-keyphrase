# Support

Consult the [troubleshooting guide](docs/troubleshooting.md),
[documentation index](docs/README.md), and [FAQ](docs/faq.md) for usage and
adoption guidance. Public issue and discussion support channels are not
enabled for this repository.

For any support report, include the module path and version, Go version,
platform, minimal reproduction, expected behavior, actual behavior, and
relevant non-secret logs. Use the private process in
[`SECURITY.md`](SECURITY.md) for vulnerabilities.

Support covers released module versions according to
[`COMPATIBILITY.md`](COMPATIBILITY.md). The `main` branch is development source,
not a supported release; published changes remain subject to the compatibility
and deprecation policies.
