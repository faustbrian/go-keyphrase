# Support

Use [GitHub Issues](https://github.com/faustbrian/go-keyphrase/issues) for
reproducible defects, documentation gaps, and bounded feature proposals.
Include the module path and version, Go version, platform, minimal reproduction,
expected behavior, actual behavior, and relevant non-secret logs.

Use [GitHub Discussions](https://github.com/faustbrian/go-keyphrase/discussions)
for adoption questions and design exploration. Use the private process in
[`SECURITY.md`](SECURITY.md) for vulnerabilities. Consult the
[troubleshooting guide](docs/troubleshooting.md) and [FAQ](docs/faq.md) before
opening a support request.

Support covers released module versions according to
[`COMPATIBILITY.md`](COMPATIBILITY.md). The `main` branch is development source,
not a supported release; published changes remain subject to the compatibility
and deprecation policies.
